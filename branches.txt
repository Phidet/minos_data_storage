# MINOS SNTP branch manifest
#
# One line per branch in the NtpSt tree. A line that is not commented out
# is exported; a leading '#' excludes it, and the note after it says why.
# Editing this file is how you change what the archive contains -- no code
# change is needed.
#
# Default policy: keep what the detector and the simulation recorded, drop
# what MINOS's reconstruction produced from it. MINOS has finished and no
# new simulations are coming, so anything dropped here is gone for good;
# prefer keeping when unsure.
#
# 171 of 755 branches enabled by default.
#
# See BRANCHES.md for what each branch means and why the excluded ones are
# excluded. If a file turns up carrying a branch this list does not mention,
# export.py names it and carries on -- add it here to archive it.
